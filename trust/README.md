# trust/

How the project decides to believe a receipt from a community Spark.

- `NODES.md`: the register of approved nodes; only Drake merges changes to it.
- `VERDICT_POLICY.md`: when two community receipts let a change merge, the spot check, the stale-judge rule, and the open items for Drake.
- `THREATS.md`: five ways this can fail, in plain words.
- `COMMUNITY.md`: the draft page for volunteers.
- `verify-evidence.sh`: reproduces `evidence/trust/` (needs a built `aien-test`).

Status 2026-10-19: policy only. Community merging is off until the judge writes its commit
into receipts (`VERDICT_POLICY.md`, "Gap"). Test results: `evidence/trust/README.md`.
